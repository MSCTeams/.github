# MSCTeams

Разрабатываем плагины для Minecraft-серверов на Java и ботов для Discord с 2024 года.

## Что мы делаем
- 🔧 Плагины под Paper и Spigot
- ⚙️ Кастомная механика, игровые системы и утилиты для серверов
- 🤖 Discord-боты (антикраш, антирейд, модерация, бэкапы)
- 📦 Поддержка и оптимизация существующих решений

## Наш стек
- Java, Maven/Gradle
- Paper API, Spigot API
- Python, disnake (Discord)
- MySQL, Redis, Git

## Наши проекты

- [CivProtect](https://github.com/msc1488/civprotect) — Защита прав OP и звёзд в LP
